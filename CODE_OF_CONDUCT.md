# Code of Conduct

## Our Commitment

AxiomForge is committed to providing a welcoming, respectful, and collaborative environment for everyone interested in technology education.

## Expected Behavior

Community members should:

* Be respectful and constructive
* Help others learn
* Share knowledge responsibly
* Accept feedback professionally
* Focus on improving the project and community

## Unacceptable Behavior

The following are not acceptable:

* Harassment or discrimination
* Personal attacks
* Intimidation
* Deliberate misinformation
* Malicious behavior
* Attempts to harm the project or its users

## Security Responsibility

Because AxiomForge involves cybersecurity education, contributors must act responsibly.

Do not:

* Use project vulnerabilities to harm others
* Abuse learning environments
* Share malicious content
* Encourage unauthorized activity

## Enforcement

Maintainers may take appropriate action when community standards are violated, including:

* Warning participants
* Removing inappropriate content
* Restricting participation
* Removing access when necessary

## Purpose

The goal of this code of conduct is to create a community where people can learn, contribute, and build technology together.
